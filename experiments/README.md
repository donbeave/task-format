# experiments

Experiment data only: fixtures, task packages, run outputs. Tooling (lint, progress-init, selftest, launch prompt) lives in `harness/` — see `harness/README.md`. Task packages for the example app are `tasks/TASK-001..007` (see `fixtures/README.md` for the seed and trusted-material spec). Headed design (herdr) in `docs/research/notes/headed-herdr-harness.md`; image/mount/gate basics in `docs/research/notes/container-harness.md`; decisions in `docs/research/RESEARCH-FINDINGS.md` §5.

Layout:

```text
fixtures/seed/                      default seed dir, mounted /seed:ro in every run (pgtui-seed.sql)
tasks/<TASK-ID>/                    README.md decisions.md verify.toml trusted/   (AGENTS.md + verify.toml-driven gate at dispatch; progress.md generated by harness/progress-init.sh into runs/<id>/progress/ — never stored here)
tasks/<TASK-ID>/trusted/            verification material the harness overlays onto the fresh clone and commits as the per-run base commit; never pushed to main
runs/<ts>-<agent>-<task>/           workspace, task-snapshot, progress/, agent-home/, out/ (tui.log, pane-id, prereqs.json, screen.txt), seed/, meta.json, prompt.txt, lint.log   (gitignored)
```

Sequence: `main` starts empty (one allow-empty bootstrap commit). TASK-001 bootstraps the cargo workspace; TASK-002..007 build the app to the full `pgtui` surface. Every artifact in the final repository is created by a task — no task assumes fixture-supplied application code. What earlier fixtures supplied (`render.rs`, font, trusted tests) is now shipped per task by the `trusted/` overlay (D-070/D-071 in each `decisions.md`).

Runs execute in persistent `--privileged` containers: the entrypoint starts an inner dockerd (storage `vfs`) for testcontainers (D19) and a standing `prereq-postgres`, so every run container needs DinD privileges and `NET_MODE=all` in v1 (egress firewall deferred, D21). TASK-004..007 additionally run live `postgres:16-alpine` containers through testcontainers. See `harness/README.md` for the per-run sequence.
