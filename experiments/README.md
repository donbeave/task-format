# experiments

Experiment data only: fixtures, task packages, run outputs. Tooling (lint, progress-init, manifest, selftest, launch prompt) lives in `harness/` — see `harness/README.md`. Task packages for the example app exist under `tasks/TASK-101..106` (see `fixtures/README.md` for the baseline fixture spec). Headed design (herdr) in `docs/research/notes/headed-herdr-harness.md`; image/mount/gate basics in `docs/research/notes/container-harness.md`; decisions in `docs/research/RESEARCH-FINDINGS.md` §5.

Layout:

```text
fixtures/<name>/                    small repos the tasks act on
tasks/<TASK-ID>/                    README.md decisions.md verify.config fixture   (AGENTS.md, verify.sh copied from reference/task-template at dispatch; protected.sha256 generated into the task dir by harness/manifest.sh; progress.md generated by harness/progress-init.sh into runs/<id>/progress/ — never stored here)
runs/<ts>-<agent>-<task>/           workspace, task-snapshot, progress.md, agent-home, transcript.jsonl, stdout.ndjson, diff.patch, verify-host.log, metrics.json   (gitignored)
```
