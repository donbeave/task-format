# experiments

Experiment data only: fixtures, task packages, run outputs. Tooling (lint, progress-init, selftest, launch prompt) lives in `harness/` — see `harness/README.md`. Task packages for the example app exist under `tasks/TASK-101..106` (see `fixtures/README.md` for the baseline fixture spec). Headed design (herdr) in `docs/research/notes/headed-herdr-harness.md`; image/mount/gate basics in `docs/research/notes/container-harness.md`; decisions in `docs/research/RESEARCH-FINDINGS.md` §5.

Layout:

```text
fixtures/<name>/                    small repos the tasks act on
fixtures/seed/                      default seed dir, mounted /seed:ro in every run (pgtui-seed.sql)
tasks/<TASK-ID>/                    README.md decisions.md verify.config fixture   (AGENTS.md, verify.sh copied from reference/task-template at dispatch; progress.md generated by harness/progress-init.sh into runs/<id>/progress/ — never stored here)
runs/<ts>-<agent>-<task>/           workspace, task-snapshot, progress/, agent-home/, out/ (tui.log, pane-id, prereqs.json, screen.txt), seed/, meta.json, prompt.txt, lint.log   (gitignored)
```

Runs execute in persistent `--privileged` containers: the entrypoint starts an inner dockerd (storage `vfs`) for testcontainers (D19) and a standing `prereq-postgres`, so every run container needs DinD privileges and `NET_MODE=all` in v1 (egress firewall deferred, D21). See `harness/README.md` for the per-run sequence.
