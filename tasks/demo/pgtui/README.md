# pgtui experimental tasks

Build the existing pgtui experiment in its original seven-task order: bootstrap,
connection store, connection form, PostgreSQL tables, preview grid, SQL queries,
and disconnect/gallery behavior.

Packages are copied from `experiments/tasks/TASK-001` through `TASK-007` without
changing their contracts or trusted assets. Canonical dependencies follow each
verifier's original predecessor contract. Only task `001` is initially ready.
