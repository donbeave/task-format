# Archive map

The active research record is the small set of pages linked from
[`README.md`](README.md). Two legacy trees remain beside it because they are
task-format inputs and must not be rewritten as documentation:

- `raw/` — captured task drafts and task-authoring material.
- `notes/` — historical investigation notes, including runtime research.

These files preserve provenance. They are not current operating guidance. Use
the active pages for the current question, method, evidence standard, and
decisions; use source code and configuration for executable behavior.
